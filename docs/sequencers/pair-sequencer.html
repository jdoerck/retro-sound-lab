Pair SequencerOne voice, a list of note/duration pairs · the simplest way an early game stored a tune

U1Pair list

Select a pair, then play a key to set its note (Z–M and Q–I on a keyboard). Durations are in video frames. The player reads one pair, holds that note for that many frames, then reads the next.

U2Two-byte format

byte 1  $01–$47  note: index into a 71-entry pitch table
        $7F      rest
        $FE      loop: jump back to the start
        $00      end of tune
byte 2  $01–$FF  duration in frames (1 to 255)
At the end
Frame rate

U3One-byte packing

bits 7–3  note  0 = rest, 1–31 = C3 up to F♯5
bits 2–0  length one of 8 preset durations
$00 (rest, shortest) is the end marker
Preset lengths (frames)

Half the size, but every note must fit 31 pitches and every duration snaps to one of 8 lengths. Red rows in the list are notes that don't fit. Switch the header to "Packed" to hear what the squeeze does.

Poly Counter Workbench4-channel polynomial-counter sound · modeled on the Atari POKEY (1979)

Play a key to start the chip.

Keys go to channels set to Keys, one note per channel. Joined 16-bit pairs count as one voice with finer tuning. Z–M and Q–I on a keyboard.

Export plays the last notes you held (or middle C) for "Hold" seconds, then releases them, with fixed channels running if Run is on. Polynomial sequences and clock behavior are modeled on the chip's design, not cycle-exact.

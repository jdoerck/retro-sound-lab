Frame TrackerPatterns, order lists and byte-code music · the way early game tunes were stored

U1Pattern editor

Instrument

Tap a cell, then play a key to enter a note (Z–M and Q–I on a keyboard). Arrows move, Delete clears, the backquote key enters a note off. Changing instrument or effect also applies it to the selected note.

U2Order list

Each entry calls a pattern, optionally transposed. A repeated pattern costs 3 bytes per channel, not a second copy of its notes. The noise channel ignores transposition.

U3Timing

Frame rate

The driver runs once per video frame. Durations are stored in rows and multiplied by this speed, so changing it rescales every note.
